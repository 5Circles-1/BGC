# Daily War Room — the operating ritual

The cadence in one line: **numbers by 19:00, variance by 19:30, tomorrow's tasks by 20:00, exercise by 20:15, huddle at 09:00 — and a missing number is treated exactly like a bad number.**

## The clock

| Time | Ritual | Owner |
|---|---|---|
| 09:00 | Huddle: yesterday's number, today's target, one focus | Sales Head |
| 09:30 | Dialling begins; speed-to-lead clock on screen | Desks A + B |
| 13:00 | Midday pacing check vs the daily ₹ line | Team Leads |
| 17:00 | Creative & campaign review | Marketing |
| **19:00** | **EOD update from every function** | All |
| **19:30** | **Variance report auto-generated** | OPERATOR M12 |
| **20:00** | **Tomorrow's task list published per function** | War Room agent |
| **20:15** | **The day's exercise issued** | Exercise agent |

Weekly: Monday WBR 10:00 · Friday compliance audit · Saturday training block.

## EOD schema (what each function submits)

- **Sales:** units + collections per product; floor dials/connects/quals; per-rep dials/connects/quals/sales/revenue; median speed-to-lead.
- **Marketing:** leads and spend per channel; creative changes.
- **Operations:** onboarding/provisioning counts, ticket status, delivery notes.
- **Finance:** reconciliation state, cash notes, exceptions.
- Day locks at 19:30; unlocking is audited. Late numbers are chased at the next huddle, by name, without drama.

## Variance logic

Compare actuals to the week's plan line (weekly run-rate ÷ 26 working days): collections, leads, dials, speed-to-lead, spend pace, connect rate. A metric ≥15% off plan is a miss. Rank misses by ₹ impact on the 60-day landing. For each miss: top two plausible root causes + the cheapest test that distinguishes them. Never report a variance without a hypothesis.

## Task generation rules (misses → tomorrow's work orders)

- Collections miss → Sales: pull cadence forward; TLs run the 13:00 check hard.
- Leads miss → Marketing: check disapprovals/budgets, shift to best-CPL channel, 2 fresh hooks to pre-flight.
- Speed-to-lead breach → Sales: fix router first thing; TL owns the on-screen clock.
- Spend above tranche → Marketing: rein budgets to plan — spend never buys through a broken rate.
- EOD missing → Management: chase at huddle ("a missing number is a bad number").
- Sign-off queue non-empty → Research: nothing releases without a name and timestamp.
- Grievance near/past due → Compliance: resolve or escalate today.
- KYC-blocked clients → Operations: chase documents; access stays locked.
- All green → raise today's stretch 10% and bank the surplus.

Tasks are specific, owned by a function, and checkable. Publish; carry-overs surface at the huddle.

## The daily exercise

One exercise at 20:15, due before the 09:00 huddle, rotating five tracks (sales, compliance, product, systems, leadership; review every 7th day). The generator adapts: close rate soft → sales drill; a compliance flag fired → compliance drill; academy running → product knowledge; EOD gaps → systems hygiene. Never the same track two days running. A 60-exercise bank ships in OPERATOR M12.

## Escalation

A week landing <70% of its collections plan triggers the recovery playbook the same Sunday — diagnose in order (CPL → show/connect → close → AOV) and fix the **first** broken rate only. Spend freezes at the last profitable level while any rate is broken.
